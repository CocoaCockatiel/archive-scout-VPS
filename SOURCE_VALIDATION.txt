Archive Scout 1.0.6.5 source validation
Date: 2026-09-17

Release scope
- Fixes repeated "CDX text response was incomplete; retrying as JSON" messages and the duplicate numbered-page requests behind them.
- Preserves v1.0.6.4 deterministic cross-platform download batching, v1.0.6.2 acquisition-only mode, v1.0.6.1 replay pacing, and v1.0.6 maximum-recall scanning.
- Database schema remains version 8. No destructive project migration is introduced.

Root cause and correction
- Automatic paging uses Wayback's /web/timemap/json endpoint first while the compact bulk-row client previously preferred line-oriented text for lower memory use.
- The path-specific Timemap JSON endpoint can ignore output=txt and return valid JSON. The text parser rejected that body, reported it as incomplete, and fetched the same page again as JSON.
- Path-specific Timemap endpoints now use their native representation first: /web/timemap/json uses JSON and /web/timemap/cdx uses line-oriented text.
- Successful bodies are representation-sniffed. Valid JSON returned for a text request and valid text returned for a JSON request are parsed locally without a second network request.
- Bodies that actually look like malformed/truncated JSON still enter the existing alternate-representation and endpoint-recovery path. The fix does not accept partial JSON as complete.

Performance and recovery invariants
- A normal successful Timemap JSON numbered page now requires one request rather than a text request followed by a duplicate JSON request.
- CDX worker count, shared 0.75-second request-start spacing, pageSize=9, rolling bounded scheduler, and response-memory bounds are unchanged.
- Per-page completion checkpoints, isolated failed-page requeue, resume-key fallback, date-window subdivision, endpoint rotation, coordinated rate-limit handling, and pause/save semantics remain unchanged.
- Existing projects and unfinished queues remain compatible.

Regression coverage
- Native Timemap JSON is used first even when compact bulk indexing prefers text.
- A valid Timemap JSON page completes with exactly one transport request.
- Valid JSON returned contrary to a text request is parsed without refetching.
- Valid text returned contrary to a JSON request is parsed without refetching.
- Malformed JSON still retries using line-oriented text and retains the prior recovery behavior.

Local automated validation
- Full suite: 228 tests run, 227 passed, 1 environment skip, 0 failed.
- Focused CDX response-recovery suite: 7 tests passed.
- Python compileall passes for archive_scout, tests, and scripts.
- Offline 100,000-row benchmark completed with 100,000 inserts, zero duplicate work, zero HTTP attempts, and zero unchanged-row rewrites.
- Release/package/workflow/Windows executable metadata target 1.0.6.5.
- Native multi-platform GitHub Actions/build smoke tests must still run on the exact release commit before publishing platform binaries.
