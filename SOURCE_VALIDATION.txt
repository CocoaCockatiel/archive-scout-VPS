Archive Scout 1.0.2 source validation
Date: 2026-08-24

Release scope
- Research Intelligence: persistent local evidence index, hybrid retrieval, entity/identifier extraction, duplicate/provenance/forum relationships, timelines, and citation-grounded optional AI deep review.
- Faster broad indexing: removed the legacy forced pageSize=9 default, preserved explicit custom page grouping, and bounded concurrent large CDX response bodies.
- Automation: packaged CLI contract with init/run/status/search/results/errors/research-index/research/ai-review, text/json/jsonl output, stable exit codes, graceful interruption, and query-only read commands.
- AI providers: provider-neutral OpenAI Responses and OpenRouter adapters; credentials remain external to project/database/report state.
- Release hygiene: active .gitignore and .github paths, ignored .env files, separate ArchiveScoutCLI build on Windows/Linux/macOS.

Indexing validation
- Broad paging uses server-selected large page grouping by default instead of forcing pageSize=9.
- Explicit smaller page grouping remains supported for constrained/troubleshooting use.
- Untouched 1.0.1 page_blocks=9 defaults upgrade to the new fast default while deliberately customized values are preserved.
- Concurrent large CDX response bodies are capped to prevent the indexing speedup from becoming a memory spike.
- Existing page-count, resume-key, year-window fallback, interrupted-index resume, shared Wayback pacing, headerless 503 coordination, and site-issue behavior remain covered and green.

Release limitations / remaining gates
- Native Windows, macOS, and Linux distributable binaries were not produced in this container because PyInstaller is not installed here.
- Build definitions were validated locally; GitHub Actions must produce and smoke-test the actual native GUI and ArchiveScoutCLI packages.
- Real Windows signing, macOS signing/notarization, and release upload transactions were not performed.
- A live Internet Archive large-site stress test was not performed; offline deterministic benchmarks do not measure Wayback server behavior.
- A live external AI provider request was not performed because source validation does not use user credentials.
- Publish tag v1.0.2 only after the GitHub Actions test matrix and native package smoke tests pass on the exact release commit.
