Archive Scout 1.0.4 source validation
Date: 2026-09-11

Release scope
- High-throughput replay release built on the complete v1.0.3 resume-key indexing architecture and schema version 7.
- Replay acquisition: new projects use 10 workers with 0.125-second shared request-start spacing (up to eight starts/second) while retaining bounded in-flight work, persistent HTTP pools, saved resume state, retries, and coordinated Wayback 429/503 host gating.
- Existing projects using the legacy untouched 4-worker / 0.5-second replay defaults migrate to the new fast defaults; deliberately customized worker/delay pairs remain unchanged.
- Parsing/scanning: native ahocorasick-rs and selectolax/Lexbor paths are declared for packaged/source installs, with the established Python implementations retained as runtime fallbacks.
- Hot-path work: literal candidate discovery and positive-match detection share one traversal, the already-normalized body is reused for normalized document hashing, and normal text downloads avoid a second full legacy-embed HTML-parser pass.
- Text coverage: .htm, .shtm, .dhtm, .xhtm, .phtm, .cgi, .php, .dat, and .txt are explicitly scannable text-page formats.
- Index-only reporting: Index URLs only now writes all_indexed_urls.txt, summary.txt, errors.txt, and site_issues.txt immediately; report regeneration also works for indexed projects with no scan run.
- Existing AI relevance, Research Intelligence, external-media workflows, deterministic scoring, review state, bot/CLI automation, project safety, and schema-v7 compatibility are preserved.

Replay-performance validation
- The default text/media replay request envelope is 10 workers with 0.125-second shared start spacing, matching an eight-starts/second high-throughput profile while preserving Archive Scout's process-wide host gate and recovery policy.
- The HTTP pool size follows the worker count, allowing ten persistent connections to overlap Wayback latency without project-sized task creation.
- Existing bounded-inflight scheduling remains max(workers, workers*2), so the faster request envelope does not create an unbounded memory queue.
- The native Aho-Corasick path releases Python-side matching work from the pure-Python automaton hot loop when the packaged dependency is present; the Python automaton remains a behavioral fallback.
- The native Lexbor path performs title, visible-text, and ordinary-link extraction from one DOM parse when selectolax is present; the Python HTMLParser remains a behavioral fallback.
- Normal download processing no longer runs the exhaustive legacy embed HTML parser immediately after ordinary page parsing; a lightweight source pass recovers old FlashVars/player configuration and the dedicated media-discovery workflow retains exhaustive parsing.

Release limitations / remaining gates
- Offline/source validation does not claim a guaranteed live Internet Archive completion rate; Wayback latency, throttling, capture size, and page complexity remain external variables. The v1.0.4 defaults match the standalone downloader's eight-request-starts/second envelope and can show higher short-window completion bursts when requests finish together.
- A live Internet Archive large-site stress test was not performed in this validation environment.
- The current validation container has no package-index network access, so the newly declared native accelerator wheels could not be installed and runtime-exercised here; the full source suite therefore exercised the retained Python fallback paths. The build/test workflow installs the runtime dependency set and must verify native imports/package smoke tests before the release tag is published.
- Native Windows, macOS, and Linux distributable binaries were not produced in this container because PyInstaller is not installed here.
- GitHub Actions must produce and smoke-test the actual native GUI and ArchiveScoutCLI packages on the release commit.
- Real Windows signing, macOS signing/notarization, and release-upload transactions were not performed.
- Publish tag v1.0.4 only after the GitHub Actions matrix and native package smoke tests pass on the exact patched release commit.
