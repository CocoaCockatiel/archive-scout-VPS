Archive Scout 1.0.6.1 source validation
Date: 2026-09-16

Release scope
- Focused performance hotfix on top of v1.0.6; schema remains version 8.
- Restores the v1.0.5 acquisition-first replay philosophy: 10 download workers and the configured 0.125-second shared replay start spacing are no longer gated by scanner backlog.
- Keeps every v1.0.6 recall, durable-resume, Search with Hitlist, URL-derived filename, skip/error audit, storage-compaction, macOS process-name, and per-page index checkpoint feature.
- Automatic indexing remains the v1.0.5/v1.0.6 Timemap profile: pageSize=9, 10 bounded workers, 0.75-second CDX request spacing, rolling queues up to 1,000 pages, and resume-key/date-window recovery fallbacks.

Performance hotfix details
- SQLite WAL synchronous mode restored from FULL to NORMAL.
- WAL auto-checkpoint restored from 4,000 to 10,000 pages.
- captures.local_path now has an index so URL-derived path collision checks do not scan giant capture tables.
- Pre-download state transitions are batched before worker submission.
- Scanner backlog is durable in SQLite and may grow independently while replay acquisition continues; only a bounded local scan window is kept in memory.
- Scanner polling is non-blocking while acquisition still has work.
- Exact-byte CoW deduplication remains available through Compact Project but is removed from the text/media replay hot path.
- Network response hashing remains one-pass while response bytes are streamed to disk.
- Progress reports replay-start, completed-download, scan, and scan-backlog rates separately.

- Added a regression test that blocks a one-worker scanner while replay acquisition continues; at least 30 of 40 replay requests must start before scanner release, proving scanner backlog cannot throttle the network feeder.
- Added checks for WAL synchronous=NORMAL, wal_autocheckpoint=10000, and captures_local_path_idx.
- Python compileall passed for archive_scout, tests, scripts, run_app.py, and run_cli.py.
- scripts/build_linux.sh and scripts/build_macos.sh passed bash syntax validation.
- git diff --check passed.
