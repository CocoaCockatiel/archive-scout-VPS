Archive Scout 1.0.6.2 source validation
Date: 2026-09-16

Release scope
- Adds the Operations-tab mode "Index and download only (no scanning)" for acquisition-first Wayback projects.
- Download-only requires a target but no keyword set, indexes the target, downloads textual captures, and intentionally creates no scan jobs, documents, document matches, Research Intelligence index, media jobs, or scan reports.
- SQLite remains schema version 8 and is retained only as the durable capture manifest/resume queue for exact original URL/timestamp mapping, local_path state, retries, errors, crash recovery, and later Search with Hitlist.
- Downloaded files remain in downloaded_unscanned state so Hitlist can search them immediately and the normal local rescan path can process them later without another Wayback request.
- The v1.0.6.1 normal download+scan pipeline and its independent scanner backlog remain available unchanged.

Acquisition-only performance details
- No scanner executor is created by download_archive_only().
- No keyword compiler/scoring path is required by the operation.
- Replay workers stream directly to .part files and retain the existing one-pass response SHA-256 result.
- Completed capture state is written in completion groups instead of creating per-file scan/document/match work.
- Persisted operation-progress commits are relaxed to a 5-second interval during download-only acquisition while UI callbacks remain live.
- Physical storage compaction remains outside the replay hot path and can be run later with Compact Project.
- The configured shared Wayback request limiter, coordinated 429/503 host pause, retry policy, resumable partial files, and network backend fallback remain intact.

Requested defaults and presets
- Download workers: 10.
- Scanner workers: 0 (automatic; unused by download-only).
- Maximum text-page size: 25 MB.
- Minimum report score: 1.
- CDX request spacing: 0.75 seconds.
- Replay request spacing: 0.125 seconds (up to 8 starts/second).
- Network backend / endpoint / index strategy: auto.
- Parallel CDX requests: 10.
- Settings page blocks: 0 (automatic); the high-throughput automatic Timemap profile still resolves to pageSize=9 internally.
- Retry base / ceiling: 5 / 300 seconds; 429/503 shared pause: 30 / 300 seconds; graceful-pause failure threshold: 8.
- System proxy/certificate environment and persistent recoverable-window retries remain enabled.
- Automatic safety backups are disabled by default; retention remains 5 and the default budget remains 1024 MB if backups are enabled.
- Removed the Ogrish-specific preset. General web archive research, Legacy forum research, Lost media discovery, and Blank project presets remain.

Local automated validation
- Full suite: 214 passed, 3 skipped, 9 subtests passed in this container.
- Download-only regression coverage patches the scanner to raise if invoked and verifies every capture still downloads successfully.
- Orchestrator regression coverage patches prepare_scan_jobs, Research Intelligence indexing, and media indexing to raise if invoked and verifies none are called.
- A downloaded-only capture is verified searchable immediately through Search with Hitlist while the documents table remains empty.
- Python compileall passed for archive_scout and tests.
- git diff --check passed.
